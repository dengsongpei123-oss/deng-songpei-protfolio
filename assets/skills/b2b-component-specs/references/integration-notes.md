## 已发现的变量缺口

原文色板给出以下数值，但“CSS Design Tokens 完整定义”代码块遗漏了对应声明。应用相关组件时，可以根据色板补充，不需要重新选色：

```css
:root {
  --color-red-10: #FFF1F0;
  --color-red-20: #FFDAD6;
  --color-red-30: #FFCCC7;
}
```

`--badge-custom-color` 和 `--dialog-width` 属于组件调用方参数。根据目标徽标颜色和对话框尺寸，在组件作用域声明；不要以为全局 Tokens 已自动提供。

## 规则冲突与适用边界

- `blue-60` 在全局色板描述中被用于禁用状态，但主要按钮状态矩阵将它用于 Hover。实现按钮时以该组件的状态矩阵为准，不把全局文字概括套用到全部控件。
- 原文要求不要硬编码颜色或像素值，但 CSS 示例自身包含尺寸矩阵中的固定数值。实施时把重复数值集中声明为语义变量，变量声明本身允许使用原文给定值；不要因此改变规定尺寸或制造不存在的 Token。
- 原文要求常规字重为 400 / 700，同时允许部分组件使用 500。仅在对应组件明确要求时使用 500。
- 全英文 UI 文案是源规范的项目约定。新页面以此为默认；修改已有中文界面时，保留用户指定语言，不擅自把整个页面翻译。
- 色板保留项或未提供色值的级别，不推断数值。只有目标组件需要该值时才说明缺口并确认。

## 实施时核对

针对实际使用的组件检查：尺寸等级、语义色、背景与边框、字体与行高、圆角、间距、浮层阴影和适用状态。排除不存在的 CSS 变量、禁用态仍可操作、焦点不可见、文字截断或长文本溢出。
