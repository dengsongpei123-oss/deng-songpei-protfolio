# 邓松培 · UI / UX 个人作品网站

蓝紫科技版，静态 HTML/CSS/SVG，可直接使用 GitHub Pages。

## 首次发布

1. 在 GitHub 新建仓库，建议名称 `deng-songpei-portfolio`，使用 `main` 分支。
2. 上传本文件夹内的全部内容，保证 `index.html` 位于仓库根目录。不要只上传 ZIP，也不要额外套一层文件夹。命令行上传会保留隐藏的 `.github` 工作流。
3. 仓库 Settings → Pages → Build and deployment → Source 选择 GitHub Actions。
4. Actions 中运行 Deploy portfolio to GitHub Pages；成功后的 Pages 地址可用于访问。

若通过网页上传时无法带入隐藏的 `.github` 目录，可改用 Settings → Pages → Deploy from a branch，选择 main / (root) 后保存。

## 内容与资源

12 个项目详情页、7 个交付作品详情页，保留高清图片展示及下载入口。
为适配 GitHub 上传限制，移除了未被页面引用的旧汇总 ZIP；OTF 与 iBanking PC 的超大 PDF 下载版由现有 2800px 高清展示图重制，页面图片不变。原网站和原始 PDF 保留在此前的网站文件夹中。PDF 下载版是图片文档，不保留原 PDF 的矢量与文本层。

本网站包含简历联系方式与作品文件，发布后访问者可以查看及下载。
